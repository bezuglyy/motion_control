# Включение по движению

Кастомная интеграция Home Assistant · v1.0.1

![icon](custom_components/motion_control/brand/icon.png)
Кастомная интеграция для Home Assistant, включающая устройства по движению.

## Возможности
- Управление освещением/устройствами по датчику движения
- Настройка времени включения/выключения, датчиков, сущностей
- Учёт времени суток (день/ночь)

## Установка
Скопируйте папку `custom_components/motion_control/` в каталог `custom_components/` конфигурации HA и перезапустите Home Assistant.
